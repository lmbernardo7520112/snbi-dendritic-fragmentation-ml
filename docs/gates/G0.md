# Gate G0 Provenance and custody

## PASS criteria

- all expected primary and documentary sources have canonical IDs;
- every available source has a SHA-256 digest and byte size;
- archive-member hash scope is explicit;
- source semantics and experimental condition are explicit;
- verification is read-only and fails closed;
- manifest validation and deterministic tests pass;
- evidence can be regenerated without frame extraction.

## Decision rule

`PASS` requires every criterion. Missing sources, hash mismatches, duplicate IDs,
unknown modalities, or incomplete evidence result in `BLOCKED`; no criterion is
silently waived.
