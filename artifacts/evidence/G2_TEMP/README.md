# Evidência G2-TEMP

Este diretório registra a correspondência temporal determinística em nível de índice. A decisão técnica proposta é **PASS com limitação documental explícita**. A evidência não afirma registro espacial ou equivalência pixel a pixel. O intervalo físico de 1,18 s é uma asserção aprovada no protocolo; sua fonte primária independente não foi localizada na TI-1.
